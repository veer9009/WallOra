# WallOra

WallOra is a polished wallpaper gallery prototype with two local roles:

- **Explore:** browse, search, filter, and download wallpapers.
- **Admin:** switch to Admin login in the header to publish a new wallpaper locally.

## Run locally

```bash
npm install
npm run dev
```

The admin flow is intentionally front-end only for this prototype. A production version should add authentication, server-side image storage, and a protected upload API.
